Samsung TV Installer

1 · Prepare the TV (one time)
  1. Connect the phone and the TV to the same Wi-Fi network.
  2. On the TV, open Apps, then press 1 2 3 4 5 on the remote (or the on-screen number pad).
  3. Turn Developer Mode on and enter this phone's IP below as Host PC IP.
  4. Restart the TV: hold the Power button until the Samsung logo appears.
  5. Find the TV's IP in Settings → General → Network → Network Status → IP Settings.
